# ARBM SIST Bare-Metal Bootstrap

Purpose: provision the permanent remote compute anchor without embedding secrets.

## Minimum host gate

- x86_64 bare metal
- >= 8 physical cores / >= 16 threads preferred
- >= 64 GB RAM
- Docker functional
- /dev/kvm available and hardware virtualization enabled
- fixed monthly billing; no metered compute overage
- remote-only heavy workloads

## First boot actions

1. Install current Ubuntu LTS.
2. Apply security updates.
3. Create a dedicated non-root `arbm-runner` account.
4. Install Docker Engine from the vendor repository.
5. Install KVM/QEMU tooling and verify `/dev/kvm`.
6. Enable firewall with SSH restricted to the authorized management path.
7. Do not expose Docker TCP socket publicly.
8. Run only the lightweight ARBM capacity probe first.
9. Promote the node only if CPU, RAM, Docker and KVM gates pass.

## GitHub runner

Use GitHub's current self-hosted runner registration command generated by the repository UI/API at provisioning time. Never commit the one-time registration token.

Labels: `self-hosted,linux,x64,arbm-heavy,baremetal,kvm,docker`

## Fail-closed

If any capacity, KVM, billing, or security gate fails, keep the node `QUALIFIED_CANDIDATE` and do not dispatch SWEfficiency/OSWorld workloads.
